# Manifesto REIS Flow

Documento interno da equipe.

Este manifesto deve ser lido antes de iniciar qualquer funcionalidade nova.

## Princípios

- Nunca interrompa o fluxo do usuário.
- Se não simplifica a vida do cliente, não entra no sistema.
- O extraordinário é um básico extremamente bem executado.
- O melhor sistema é aquele que o usuário não precisa aprender.
- Cada clique precisa ter um motivo.
- Dados importantes primeiro. Dados complementares depois.
- O sistema deve trabalhar para o usuário, nunca o contrário.

## Regra de Trabalho

Toda vez que você for desenvolver uma funcionalidade, leia esse manifesto antes de começar.

## Visão de Longo Prazo

E aí, quando chegar o dia, você vai perceber uma coisa curiosa: as pessoas provavelmente vão perguntar sobre arquitetura, IA, banco de dados e tecnologia. Mas, quando REIS Flow realmente der certo, o motivo não vai ser nenhum desses. Vai ser porque, desde o começo, você decidiu que **cada tela tinha que respeitar o tempo de quem estava trabalhando**. Isso é o tipo de filosofia que sobrevive mesmo quando a tecnologia muda.
